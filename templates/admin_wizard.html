🧙‍♂️ Мастер установки нового сервера
Всё, что раньше делалось руками в терминале (ssh-copy-id, установка AmneziaWG, заливка скриптов), выполнится автоматически. Нужен только IP и root-пароль от нового VPS. Пароль нигде не сохраняется.
Используется один раз — для передачи SSH-ключа. Дальше бот ходит по ключу.
⏳ Идёт установка — 1–5 минут. Не закрывайте страницу: скачивается docker-образ. По окончании здесь появится подробный лог по шагам.
📋 Как запускать новый сервер (инструкция)
  1. Купите VPS Ubuntu 22.04/24.04 (минимум 1 CPU / 512MB). Сохраните IP и root-пароль (приходят в панели хостера или на почту).
  2. Если у вас НЕ стандартный SSH-порт 22 — бот ходит на порт 2222. В мастере укажите тот, что сейчас (обычно 22 для нового VPS).
  3. Запустите мастер слева. Он сам: передаст SSH-ключ, поставит AmneziaWG (docker + контейнер amnezia-awg2) со случайным защитным UDP-портом, настроит NAT, зальёт скрипты выдачи/удаления конфигов и занесёт сервер в базу.
  4. В конце мастер покажет внешний UDP-порт AmneziaWG. Если у хостера есть внешний firewall (Cloud-сети/Security Groups) — откройте этот UDP-порт в его панели.
  5. Проверка: «Клиенты» → выдайте себе тестовый доступ на новый сервер → импортируйте конфиг в AmneziaWG на телефоне и включите.
  6. Цены на сервер задаются отдельно: страница «Серверы» (если пусто — действуют глобальные из «Настроек»).
🛠 Что делает автоустановщик (шаблон)
  • docker + образ amneziavpn/amneziawg-go
  • конфиг awg0.conf с параметрами обфускации (Jc/Jmin/Jmax, H1-H4…)
  • ip_forward, NAT MASQUERADE, сохранение правил iptables
  • случайный внешний UDP-порт (10000–59999)
  • SSH-ключ бота в authorized_keys
  • add_user.sh/remove_user.sh в /root/ (+chmod, чистка переносов)
