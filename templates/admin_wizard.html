🧙‍♂️ Мастер подключения сервера
Рекомендуемый сценарий: сначала 1–4 шага инструкции справа (подготовка сервера + установка Amnezia официальным приложением), потом эта форма. Мастер сам докинет SSH-ключ бота, проверит контейнер, зальёт скрипты выдачи конфигов и занесёт сервер в базу. Если Amnezia на ноде ещё нет — мастер попробует поставить её сам, но проверенный путь — приложение. Пароль нигде не сохраняется.
обычно 2222 — см. шаг 3 инструкции справа
Используется один раз — для передачи SSH-ключа. Дальше бот ходит по ключу.
⏳ Идёт установка — 1–5 минут. Не закрывайте страницу: скачивается docker-образ. По окончании здесь появится подробный лог по шагам.
📋 Подготовка нового сервера (перед запуском мастера)
Сервер бота НЕ может подключаться к внешнему порту 22 (у его хостера закрыт исходящий TCP/22), поэтому SSH ноды обязан слушать также на 2222. Все 7 шагов занимают ~15 минут, 1–4 делаются один раз на новом VPS.
  1. Купите VPS Ubuntu 22.04/24.04, KVM (не OpenVZ/LXC: проверить позже можно командой systemd-detect-virt → должно быть kvm). Сохраните IP и root-пароль.
  2. Firewall хостера (в его веб-панели): откройте TCP 2222, источник 0.0.0.0/0. Сюда же позже откроем UDP-порт Amnezia (шаг 6).
  3. Включите второй SSH-порт 2222 (через VNC/веб-консоль хостера на самом VPS).
    Общая проверка какой у вас вариант: systemctl status ssh.socket --no-pager
    • Ubuntu 24.04 (ssh.socket активен): 
      mkdir -p /etc/systemd/system/ssh.socket.d
cat > /etc/systemd/system/ssh.socket.d/listen.conf <<'EOF'
[Socket]
ListenStream=
ListenStream=22
ListenStream=2222
EOF
systemctl daemon-reload
systemctl restart ssh.socket
    • Ubuntu 22.04 и старее (обычный sshd): echo -e "Port 22\nPort 2222" >> /etc/ssh/sshd_config && systemctl restart sshd
    Проверка: ss -tlnp | grep sshd — должны слушаться оба порта 22 и 2222. И с компьютера ssh root@IP -p 2222 — пускает.
  4. Установите Amnezia официальным приложением со своего компьютера (с вашего ПК порт 22 доступен — это нормально): в приложении добавьте сервер (IP / порт 22 / root / пароль), выберите установку AmneziaWG, дождитесь конца, создайте в приложении тестового клиента и подключитесь им — убедитесь, что VPN реально работает. Этот шаг — наш проверенный боевой способ; контейнер amnezia-awg2 приложение создаст само.
  5. Запустите мастер слева: IP, SSH-порт 2222, root-пароль. Мастер докинет SSH-ключ бота, проверит здоровье контейнера (при необходимости — подремонтирует), зальёт add_user.sh/remove_user.sh и внесёт сервер в продажу.
  6. Откройте внешний UDP-порт — мастер покажет его в журнале в конце (например 40158/udp). Откройте его в firewall-панели хостера (UDP, 0.0.0.0/0).
  7. Проверка через бота: «Клиенты» → тестовый доступ на новый сервер → конфиг на телефон → включить. Дальше сервер в продакшене.
🚑 Если не сработало — распознавание по ошибке
timed out на шаге подключенияПакеты не доходят: в форме указан не 2222, либо в панели хостера TCP 2222 не открыт/открыт не для всех. Также бывает, если мастер пытаются кормить портом 22 — с сервера бота 22 недоступен и не будет.
unable to connect к порту 2222Дошло, но SSH на 2222 не слушает → шаг 3 не сделан (или сервер переустановили — тогда шаг 3 повторить заново, всё слетает).
REMOTE HOST IDENTIFICATION HAS CHANGEDНорма после переустановки сервера: host-ключи сменились. С компьютера: ssh-keygen -R <IP> (и при необходимости ssh-keygen -R "[<IP>]:2222"), потом повторный ssh → напечатать yes.
is restarting/логи пустые у amnezia-awg2Битый «заводской» контейнер из образа хостера. Решение: удалить контейнер и установить Amnezia через приложение (шаг 4) — или просто запустите мастер еще раз: он попробует авто-ремонт.
Мастер завершился✅, но VPN не пропускает трафикНе открыт внешний UDP-порт в firewall-панели хостера (шаг 6) — самая частая пропущенная деталь.
Amnezia не встаёт и приложением тожеПроверьте ls /dev/net/tun и systemd-detect-virt: файла нет или не kvm — тариф/хостер не годится, включите «TUN/TAP» у хостера либо берите другой VPS.
