🧙‍♂️ Мастер подключения сервера
Рекомендуемый сценарий: сначала 1–4 шага инструкции справа (подготовка сервера + установка Amnezia официальным приложением), потом эта форма. Мастер сам докинет SSH-ключ бота, проверит контейнер, зальёт скрипты выдачи конфигов и занесёт сервер в базу. Если Amnezia на ноде ещё нет — мастер попробует поставить её сам, но проверенный путь — приложение. Пароль нигде не сохраняется.
обычно 2222 — см. шаг 3 инструкции справа
Используется один раз — для передачи SSH-ключа. Дальше бот ходит по ключу.
⏳ Идёт установка — 1–5 минут. Не закрывайте страницу: скачивается docker-образ. По окончании здесь появится подробный лог по шагам.
📋 Подготовка нового сервера — простыми словами
Почему всё именно так: сервер бота (где крутится бот) не может стучаться в стандартную «дверь» SSH №22 — его собственный провайдер закрыл выход. Поэтому мы договариваемся стучаться в дверь №2222, и на каждом новом сервере её рядом с привычной №22 открываем одной командой (шаг 3).
🧒 Словарик:
Порт — номер «двери» на сервере (от 1 до 65535). SSH стоит за дверью 22 (мы добавим 2222), а трафик ваших клиентов пойдёт за дверью с номером вида 40158.
TCP — «по бумажкам» (подходит для команд и входа — SSH). UDP — «на голос» (подходит для VPN-данных, так трафик клиентов бежит быстрее).
Firewall — охранник на входе у хостера: если двери нет в его списке разрешённых — никто не пройдёт.
0.0.0.0/0 — «все адреса интернета». Пишется в поле «источник»: впускать с любого IP.
  1. Купите VPS. В панели хостера: тариф Ubuntu 22.04 или 24.04, виртуализация KVM — и получите по почте/в панели IP (например 45.12.34.56) и root-пароль. Сохраните — они нужны в шагах 3–5.
  2. Проверьте дверь 2222 у «охранника» хостера. В панели хостера найдите раздел «Firewall» / «Файрвол» / «Сеть» (у некоторых хостеров его нет — тогда здесь ничего делать не надо, всё и так открыто). Добавьте правило и заполните его примерно так:
    протокол = TCP · порт = 2222 · источник = 0.0.0.0/0
    Читается так: «пускать всех, кто стучится в дверь 2222 обычными письмами (TCP)». Сюда же в шаге 6 добавим дверь для трафика VPN.
  3. Откройте на самом сервере дверь 2222 (команды вводятся в VNC/веб-консоль хостера — чёрный экран терминала вашего сервера).
    Сначала узнайте, какой у вас вариант: systemctl status ssh.socket --no-pager
    • Увидели слово «active» → Ubuntu 24.04, вот эти команды целиком: 
      mkdir -p /etc/systemd/system/ssh.socket.d
cat > /etc/systemd/system/ssh.socket.d/listen.conf <<'EOF'
[Socket]
ListenStream=
ListenStream=0.0.0.0:22
ListenStream=0.0.0.0:2222
EOF
systemctl daemon-reload
systemctl restart ssh.socket
      ⚠️ «0.0.0.0:» в командах — не опечатка: так мы явно просим слушать для IPv4. Без него иногда слушает только на IPv6 ([::] в выводе) — и бот достучаться не может.
    • Написало «not found / no such» → Ubuntu 22.04, одна команда:
      echo -e "Port 22\nPort 2222" >> /etc/ssh/sshd_config && systemctl restart ssh
    Проверка обязательно: ss -tlnp | grep sshd — в ответе две строки: порт 22 и порт 2222. И с вашего компьютера: ssh root@ВАШ-IP -p 2222 — пускает.
  4. Поставьте Amnezia через официальное приложение (на своём компьютере — с него дверь 22 доступна, всё честно): в приложении «+» → «У меня есть данные доступа» (или «Добавить сервер») → впишите IP, порт 22, логин root, пароль → выберите AmneziaWG → «Установить». Ждите 2–5 минут. Как закончит — создайте в приложении тестового клиента, скачайте конфиг и включите: побежал ли через VPN интернет — значит, контейнер amnezia-awg2 жив и всё готово.
  5. Теперь мастер (форма слева). Впишите: IP, SSH-порт 2222, root-пароль → кнопка «🚀 Установить сервер». Он сам зайдёт, проверит контейнер (при необходимости — подремонтирует), скинет скрипты выдачи конфигов и впишет сервер в «продажу».
  6. Откройте у охранника дверь для трафика клиентов. В конце журнала мастер напишет «внешний UDP-порт: 40158» — это дверь, по которой пойдут ваши клиенты. Вернитесь в тот же раздел Firewall (как в шаге 2) и добавьте правило:
    протокол = UDP · порт = тот, что назвал мастер (у вас свой номер, не обязательно 40158) · источник = 0.0.0.0/0
    ⚠️ UDP, не TCP — частая путаница. Забыли шаг — клиенты подключатся к VPN, но интернет не будет грузиться.
  7. Проверка через бота: «Клиенты» → тестовый доступ на новый сервер → конфиг импортируйте в AmneziaWG на телефоне → включите. Сайты открываются — сервер в боевом составе.
🚑 Если не сработало — распознавание по ошибке
timed out на шаге подключенияПакеты не доходят: в форме указан не 2222, либо в панели хостера TCP 2222 не открыт/открыт не для всех. Также бывает, если мастер пытаются кормить портом 22 — с сервера бота 22 недоступен и не будет.
unable to connect к порту 2222Дошло, но SSH на 2222 не слушает → шаг 3 не сделан (или сервер переустановили — тогда шаг 3 повторить заново, всё слетает).
REMOTE HOST IDENTIFICATION HAS CHANGEDНорма после переустановки сервера: host-ключи сменились. С компьютера: ssh-keygen -R <IP> (и при необходимости ssh-keygen -R "[<IP>]:2222"), потом повторный ssh → напечатать yes.
is restarting/логи пустые у amnezia-awg2Битый «заводской» контейнер из образа хостера. Решение: удалить контейнер и установить Amnezia через приложение (шаг 4) — или просто запустите мастер еще раз: он попробует авто-ремонт.
Мастер завершился✅, но VPN не пропускает трафикНе открыт внешний UDP-порт в firewall-панели хостера (шаг 6) — самая частая пропущенная деталь.
Amnezia не встаёт и приложением тожеПроверьте ls /dev/net/tun и systemd-detect-virt: файла нет или не kvm — тариф/хостер не годится, включите «TUN/TAP» у хостера либо берите другой VPS.
